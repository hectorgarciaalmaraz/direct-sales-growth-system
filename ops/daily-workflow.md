# daily-workflow.md — The daily cockpit (~60–90 min)

> Rutina diaria en Claude Code. Tiempo configurable (`config/business-profile.md`, default
> 60–90 min). Publicación **manual**. Todo lo publicable pasa por `compliance-guard`.

## 0. Abrir (2 min)
- Abre el proyecto en Claude Code. Revisa `strategy/weekly-plan.md` (idea de hoy) y
  `crm-tracker due` (seguimientos del día).

## 1. Pedir el batch del día (15–25 min)
Di algo como: **"dame el contenido de hoy"**. El sistema entrega:
- Guion(es) es-MX (`script-writer`) — faceless + presentador.
- Adaptación a 4 plataformas (`repurpose-engine`).
- Prompts de IA (`video-/image-/voice-prompt-studio`) para Higgsfield/Veo/ElevenLabs.
- Captions + hashtags + mejor horario por plataforma (`caption-writer`).
- Todo revisado por `compliance-guard`.

## 2. Producir y publicar (20–35 min)
- Genera/edita en tus herramientas (Higgsfield/Veo/ElevenLabs/Premiere).
- **Publica manualmente** en cada red (el sistema no publica).

## 3. Conversaciones: ventas y reclutamiento (10–20 min)
- Responde comentarios/DMs con `sales-funnel` / `recruitment-funnel`.
- Mueve a WhatsApp lo que fluya. Sé honesto, sin promesas/claims.
- Registra prospectos y próximos pasos con **"agrega este prospecto"** (`crm-tracker`).

## 4. Registrar resultados (5 min)
- Anota el día en `ops/metrics.csv` (posts, reach, saves, comments, dms, leads, sales,
  recruits, notes).
- Verifica floors: **≥1 venta/día**, y vas por **≥1 recluta/semana**.

## Checklist diario
- [ ] Publiqué en mis plataformas prioritarias (TikTok + IG al menos).
- [ ] Hice ≥1 oferta de venta clara.
- [ ] Atendí DMs/comentarios y registré leads.
- [ ] Di seguimiento a los `due` de hoy.
- [ ] Registré métricas.
- [ ] Todo lo publicado pasó por `compliance-guard`.

## Atajos (frases que activan skills)
- "dame el contenido de hoy" → planner + script + repurpose + prompts + caption
- "cómo le respondo a esta clienta/prospecto" → sales/recruitment-funnel
- "agrega este prospecto" → crm-tracker
- "revisa que esto cumpla" → compliance-guard
