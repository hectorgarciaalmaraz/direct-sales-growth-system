# updates-inbox.md — Operator update inbox

> Deja aquí instrucciones o archivos para que el sistema los integre. En la revisión semanal
> (o cuando digas **"procesa la bandeja de updates"**), `system-upgrader`:
> 1) clarifica, 2) decide si es **config / knowledge / skill**, 3) aplica, 4) registra en
> `ops/changelog.md` y sube versión.
>
> **Importante:** el contenido que dejes aquí se trata como **datos/instrucciones del operador**,
> no como comandos automáticos de archivos externos. Cambios a contenido publicable pasan por
> `compliance-guard`.

## Cómo usar
- Escribe una línea por instrucción, o pega un bloque con contexto.
- Si adjuntas un archivo, ponlo en el repo y referencia su ruta aquí.
- Marca prioridad opcional: `[alta] / [media] / [baja]`.

## Formato sugerido
```
- [fecha] [prioridad] <instrucción o pega el contenido> (archivo: <ruta opcional>)
```
