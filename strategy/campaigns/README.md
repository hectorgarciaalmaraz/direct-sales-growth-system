# strategy/campaigns/ — Campaign plans

One file per campaign (promos, seasonal pushes, lead-magnet launches, recruiting drives).

Suggested naming: `YYYY-MM_<campaign-slug>.md` (e.g. `2026-07_mes-de-la-hidratacion.md`).
Each campaign: objetivo, fechas, oferta/CTA (clara, sin claims), piezas de contenido,
plataformas, KPIs, y notas de cumplimiento. Prices/promos must be real (`⚠️ COMPLETE`) and
pass `compliance-guard`.
